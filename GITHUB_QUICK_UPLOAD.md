# 📤 GitHub Upload - One Page Quick Reference

## ⚡ 7 Simple Steps

### 1️⃣ Open Terminal
```bash
cd c:\Users\ANKIT SINGH\OneDrive\Desktop\ILP
```

### 2️⃣ Initialize Git
```bash
git init
```

### 3️⃣ Add Files
```bash
git add .
```

### 4️⃣ Commit Files
```bash
git commit -m "Initial commit - IPL Data Platform"
```

### 5️⃣ Create GitHub Repository
- Go to: https://github.com
- Click **+** → **New repository**
- Name: `ipl-data-platform`
- Click **Create repository**
- **Copy the HTTPS link** (you'll need it next)

### 6️⃣ Add Remote URL
```bash
git remote add origin https://github.com/YOUR-USERNAME/ipl-data-platform.git
```
*(Replace YOUR-USERNAME with your GitHub username)*

### 7️⃣ Push to GitHub
```bash
git branch -M main
git push -u origin main
```

## 🆘 Common Issues

| Problem | Solution |
|---------|----------|
| Git not found | Download: https://git-scm.com |
| Authentication error | Use Personal Access Token (not password) |
| Repository not found | Check URL and permissions |
| Nothing to commit | Make changes first, then commit |
